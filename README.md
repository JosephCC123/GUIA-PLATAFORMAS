# GUIA-PLATAFORMAS

Bitácora estática (HTML simple) con las guías del curso de Arquitectura de Plataformas.
Cada guía se desarrolla localmente (normalmente ASP.NET Core), se genera su informe en PDF
y Word, y ambos quedan en `docs/` con un enlace de descarga en `index.html`.

Pensado para desplegarse en Netlify apuntando a la raíz del repo (sitio estático, sin build).

## Estructura

- `index.html` — página única con la lista de guías y sus botones de descarga.
- `docs/` — PDFs y DOCX de cada informe.
